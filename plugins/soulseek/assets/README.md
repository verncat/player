# Soulseek logo

The Soulseek bird mark is sourced from [selfh.st Icons](https://github.com/selfhst/icons),
using the [Soulseek PNG asset](https://github.com/selfhst/icons/blob/main/png/soulseek.png).
See the [upstream license](https://github.com/selfhst/icons#license) for attribution and licensing.

`soulseek.png` is included unmodified and embedded as a data URL in `../plugin.json`,
so the plugin card displays the logo without a network request.
